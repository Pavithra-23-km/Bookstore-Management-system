# 📚 Bookstore Management System - SQL Project

A complete end-to-end Database Management System designed for an Online Bookstore using Oracle SQL. This project manages books, authors, customers, and orders efficiently.

> Created by Pavithra K M | DBMS Project

### 🔗 Live Project Link: https://github.com/Pavithra-23-km/Bookstore-Management-system

---

### ✨ Features
-  **6+ Relational Tables** - Authors, Books, Customers, Orders, Genres, Order Details
-  **Primary Key & Foreign Key Constraints** - Ensures data integrity
-  **Data Insertion** - Realistic sample data for testing
-  **Views Created** - Simplified data access for reports (3 Views)
-  **Main Queries** - JOIN operations for Customer Orders, Best Selling Books, Revenue Reports
-  **Indexes** - Optimized query performance
-  **Screenshots** - Proof of execution for all queries
